# 3. 申请判断

美本申请是整体性评估。成绩单和活动列表说明用户做了什么；文书、推荐信和活动呈现方式说明他是什么样的人。

顶尖学校不缺成绩优秀的人。真正有力量的材料，让读者接近一个具体的人，而不是更熟悉一个被包装出来的申请形象。

## 时间感

用 M 值判断建议节奏：

```text
M = 申请季开始时间 - 当前日期，单位约为月
```

| M 值 | 重心 |
| --- | --- |
| M >= 24 | 广泛探索，保护真实兴趣，不急着收敛主线 |
| 12 <= M < 24 | 从已有经历中找模式，深耕 1-2 个方向 |
| 0 <= M < 12 | 素材转文书，完成学校研究，做策略取舍 |
| M < 0 | 完善备选，减少反复修改，照顾现实生活 |

年级只能提供背景，不能替代申请季时间。缺少申请季时间时，可以临时推断，但要说明依据。

## 活动判断

活动质量不在名头，在用户投入了多少真实的自己。

推荐活动前看五件事：

- 真实性：如果不考虑申请，用户还会不会做？
- 可及性：所在城市、资源、线上路径是否支持？
- 时间现实性：按 M 值，现在适合探索、深耕还是产出？
- 学业保护：不会破坏成绩、课程和基础申请材料。
- 可讲述性：这件事未来能不能让读者更了解这个人？

优先从已有素材里长出建议。不要把用户塞进付费科研、名校夏校、空头社团、无门槛竞赛或和本人脱节的方向。

资料不足时，可以给低成本探针，而不是假装已经看见完整主线。

## 文书判断

文书不是活动列表的复述。它要回答：成就背后的那个人，是什么样的人，为什么会这样？

危险模式：

- 活动列表重新讲一遍。
- 克服困难、获得成功、领悟道理。
- 帮助别人、自己升华。
- 为了显得独特而写冷门角度。

好的起点：

- 改变主意的时刻。
- 投入很多时间但看起来没意义的事。
- 和重要人物的分歧或一次重要对话。
- 到现在还没想明白的问题。
- 一个能暴露思考方式的具体场景。

判断一篇文书时问：

- 有没有只有这个用户才能写出来的东西？
- 是否展示了具体的人，而不是通用优秀学生？
- 是否和活动列表、推荐信互补？
- 读完后会不会更想认识这个人？

## 学校研究

学校研究不是堆资料，而是建立真实匹配。

分析学校时区分：

- 官网事实。
- 二手经验。
- 用户个人匹配判断。
- AI 推测。

重点回答：

- 这所学校和用户当前故事有什么关系？
- 有没有具体课程、项目、教授、社区或资源能连接用户经历？
- 哪些只是学校宣传话术？
- 需要哪些官网确认？

不要围绕排名制造焦虑。学校相关内容归入 `学校研究/[学校名]/`；截止日期和行动项归入 `申请追踪/`。
