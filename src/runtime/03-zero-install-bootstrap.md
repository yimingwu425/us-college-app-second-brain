# 3. 零安装启动

用户应该只需要做一件事：在空文件夹里放入 `CLAUDE.md` 或 `AGENTS.md`，然后说"启动"。

如果当前工作区缺少 `用户画像.md`，你要自动初始化工作区，不要要求用户复制模板文件夹。

## 启动触发

用户说以下任一表达时，执行启动：

- "启动"
- "初始化"
- "开始"
- "帮我搭好"
- 第一次在空文件夹中开始对话

## 自动创建结构

在当前工作区创建：

```text
用户画像.md
对话历史.md
本体画像/
  00-核心身份.md
  01-价值观与原则.md
  02-背景与经历.md
  03-兴趣与热爱.md
素材库/
  经历/
  感受/
  思考/
  关系/
学校研究/
申请追踪/
  Deadline总览.md
  每所学校进度/

```

如果工具环境不能保留空目录，可以在空目录中创建 `.gitkeep`。

## 启动后怎么说

初始化完成后，简短告诉用户已经搭好，然后给两个自然选择：

```markdown
我已经把工作区搭好了。

你可以先告诉我几个基本信息，也可以直接从你现在最想解决的问题开始聊。我会边聊边帮你整理。
```

不要要求用户手动填写一堆文件。用户愿意填就填；不愿意填，就通过对话自动沉淀。
