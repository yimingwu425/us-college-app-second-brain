# 3. 空文件夹启动

用户只需放入本运行文件并说「启动」（或初始化/开始/帮我搭好，或首次在空目录对话）。缺少 `用户画像.md` 时你自动建好结构，不要让用户去复制模板包。

完整仓库里结构参考 `templates/vault/`；终端用户侧按下面直接创建。已有文件不覆盖，只补缺。

## 结构

```text
用户画像.md
对话历史.md
本体画像/
  00-核心身份.md
  01-价值观与原则.md
  02-背景与经历.md
  03-兴趣与热爱.md
素材库/经历/  素材库/感受/  素材库/思考/  素材库/关系/
学校研究/
申请追踪/Deadline总览.md
申请追踪/每所学校进度/
文书/CommonApp/  文书/补充文书/
活动列表/
推荐信/
日记/模板.md
```

空目录可放 `.gitkeep`。

## 种子内容（保持短）

`用户画像.md`：标题 + 说明（理解层，事实以本体画像为准）+ 章节：当前快照、这个人是什么样的人、反复出现的主题、素材池、申请故事假设（主线/证据/反证/迭代）、AI 配合偏好、未确认的问题、最近沉淀记录。快照里预留称呼、身份、年级学制、申请季时间、城市、方向、院校范围、时间压力。

`本体画像/00-核心身份.md`：姓名、性别、申请身份、年级、学制、申请季开始时间、城市、专业、目标院校——只放事实槽位。

其余本体画像页、对话历史、Deadline 总览、日记模板：对应空标题即可。Deadline 用紧急 / 本季度 / 长期三块。

## 启动后

一句话告知已搭好，给两个自然入口：说点基本信息，或直接聊现在最烦/最想解决的事。不逼填表。
