# Vault 模板（唯一真相源）

本目录是工作区结构的唯一模板源。

- 用户日常使用：通常只需复制 `dist/CLAUDE.md` 或 `dist/AGENTS.md` 到空文件夹，说「启动」；agent 会按 runtime 中的零安装规则创建等价结构。
- 维护者修改模板：只改这里，不要再维护第二套 `templates/` 平铺副本。
- 职责划分：
  - `本体画像/`：用户可手改的事实底稿
  - `用户画像.md`：AI 维护的理解层
  - `素材库/`：原始经历与细节
  - `学校研究/`：学校事实与个人匹配
  - `申请追踪/`：截止日期与进度
  - `文书/`、`活动列表/`、`推荐信/`：可提交产物与版本
  - `对话历史.md`：重要会话索引
  - `日记/`：私人记录
