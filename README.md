# 美本申请第二大脑 (US College App Second Brain) v4.0-modern

> 第一性原理：招生官在找活生生的人。

美本申请第二大脑是一套给中国高中生使用的 AI 申请陪跑框架。它不是活动清单生成器，也不是中介话术库，而是一个围绕“真实的人”持续积累素材、记忆、文书线索、学校研究和申请追踪的工作区。

v4.0-modern 是一次重新设计：它不再围绕阶段、固定话术和多层记忆关卡运行，而是把现代 AI 当作有判断力的申请伙伴。普通用户只需要在空文件夹里放一个 `CLAUDE.md` 或 `AGENTS.md`，然后对 agent 说"启动"，它会自动搭好工作区。

## 适合谁

- 正在准备美国本科申请的中国高中生
- 想长期积累真实素材，而不是临时包装申请故事的学生
- 希望 AI 记住自己的背景、价值观、活动、文书线索和学校研究的人
- 想把 Claude / AI 工具变成申请季第二大脑的家庭或顾问

## 核心能力

- **动态用户画像**：用 `用户画像.md` 维护身份、时间压力、稳定特质、素材池、故事假设和 AI 配合偏好。
- **零安装启动**：空文件夹里只放一个运行文件，agent 收到"启动"后自动创建全部资料结构。
- **自动沉淀**：AI 主动识别有长期价值的信息，写入 `用户画像.md`、素材库、学校研究、申请追踪或对话历史。
- **轻量资料系统**：`素材库/`、`学校研究/`、`申请追踪/` 和 `对话历史.md` 只服务于具体资料，不再模拟复杂记忆层。
- **M 值时间轴**：根据“申请季开始时间 - 当前日期”判断探索期、聚焦期、产出期或等待期。
- **活动判断**：优先从真实兴趣和已有素材里生长活动方向，避免模板化包装。
- **文书判断**：帮助寻找只有这个学生能写出来的角度，而不是复述活动列表。
- **学校研究与申请追踪**：记录学校信息、deadline、ED/EA/RD 进度和待办事项。

## 快速开始

1. 新建一个空文件夹。
2. Claude 用户把 `dist/CLAUDE.md` 放进去并命名为 `CLAUDE.md`；Codex/通用 agent 用户把 `dist/AGENTS.md` 放进去并命名为 `AGENTS.md`。
3. 开一个新的 AI 对话，说：`启动`。
4. agent 会自动创建 `用户画像.md`、`素材库/`、`学校研究/`、`申请追踪/` 等文件和目录。

更完整的安装说明见 [docs/setup.md](docs/setup.md)。

## 日常怎么用

你可以把它当作申请季的长期对话工作区：

- 想到一个活动、项目、比赛、课程或阅读感受，直接丢给 AI。
- 有学校官网、申请案例、专业介绍或 deadline，发给 AI 让它整理进学校研究或申请追踪。
- 不知道文书写什么时，先聊经历、困惑、冲突、改变主意的时刻，而不是直接让 AI 写成稿。
- 每次重要对话后，AI 会自动沉淀新线索到 `用户画像.md`、`素材库/`、`学校研究/` 或 `申请追踪/`。
- 当你感觉 AI 说偏了，直接指出，它会把明确偏好写进 `用户画像.md`。

agent 初始化后的核心目录包括：

```text
用户画像.md    AI 持续维护的动态用户画像
本体画像/      基本身份、价值观、背景、兴趣
素材库/        经历、感受、思考、关系
学校研究/      学校信息和个人匹配思考
申请追踪/      Deadline 和每所学校进度
对话历史.md    重要会话摘要
日记/          私人记录
```

## v4.0-modern 仓库结构

- `dist/CLAUDE.md`：Claude 用户复制使用的完整运行文件。
- `dist/AGENTS.md`：Codex/通用 agent 用户复制使用的完整运行文件。
- `templates/vault/`：参考模板；实际使用时可以只放一个运行文件，让 agent 自动创建。
- `src/runtime/`：维护者编辑的现代运行提示源码。
- `src/manifest.md`：`dist/CLAUDE.md` 和 `dist/AGENTS.md` 的拼装顺序。
- `scripts/build-dist.sh`：从 `src/runtime/` 生成 `dist/CLAUDE.md` 和 `dist/AGENTS.md`。
- `docs/setup.md`：安装说明。
- `docs/design.md`：架构说明。
- `examples/demo-vault/`：示例工作区说明。

## 维护方式

如果你要修改系统规则，不要直接编辑 `dist/` 里的生成文件。

1. 修改 `src/` 下对应模块。
2. 确认 `src/manifest.md` 顺序正确。
3. 运行：

```bash
./scripts/build-dist.sh
```

4. 检查生成后的 `dist/CLAUDE.md` 和 `dist/AGENTS.md`。
